Codex Classroom Demo

One prompt, public data, and a mobile-friendly map-and-chart build.

This repo is the staging ground for a live Codex prompt that will pull public Library of Congress newspaper data, turn it into a reusable dataset, and publish an interactive browser demo without any API keys or server code.

In broad terms, the prompt will ask for a national time series and a state-level choropleth snapshot for the same search term, all generated from one pass inside this repo.
