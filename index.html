Live Demo Preview

A prompt will turn public newspaper data into interactive visuals.

This GitHub Pages site is the working home for a live Codex prompt that will try to pull public Library of Congress newspaper data, shape it into a reusable JSON dataset, and publish a small browser-based visualization without any server code.

In broad terms, the prompt will ask for a national trend line over time and a state-level choropleth snapshot for the same search term, all generated inside this repo from a single request.

A fallback test implementation is available at index-test.html. Source lives in the vibedemo repository.
